# Classification with neural networks

Binary classification with neural networks, in NumPy. Done so far: the first five tasks of the project, a single neuron (logistic-regression unit). Next: gradient descent and training, then a network with one hidden layer, a deep network, and multiclass classification with one-hot encoding and softmax.

| File | Feature |
|---|---|
| `0-neuron.py` | `Neuron` with weights, bias and activated output |
| `1-neuron.py` | Private attributes with getters |
| `2-neuron.py` | Forward propagation (sigmoid activation) |
| `3-neuron.py` | Logistic-regression cost |
| `4-neuron.py` | Evaluation: predictions and cost |

The demo scripts (`N-main.py`) expect the course dataset `../data/Binary_Train.npz`, which isn't included.

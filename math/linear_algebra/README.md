# Linear algebra

Matrix operations, first in pure Python (shape, transpose, element-wise addition, concatenation, multiplication), then with NumPy (`np_shape`, `np_transpose`, `np_elementwise`, `np_cat`, `np_matmul`, slicing along arbitrary axes with `np_slice`).

Concepts: vectors and matrices, shape and axes, slicing, element-wise operations, concatenation, dot product and matrix multiplication, broadcasting, and why vectorised (parallel) code matters.
